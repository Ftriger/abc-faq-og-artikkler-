## SCHEMA MARKUP FOR LOKALBEDRIFT (LocalBusiness)

For å styrke lokal SEO, legg til dette i `<head>` på kontakt- og hjemmeside:

```json
{
  "@context": "https://schema.org",
  "@type": "LocalBusiness",
  "name": "ABC Fallsikring",
  "url": "https://www.abcfallsikring.no",
  "description": "Profesjonell leverandør av fallsikring og sikkerhetsutstyr for arbeid i høyden i Norge. Vi tilbyr installasjon, kontroll, kurs og rådgivning.",
  "areaServed": "Norge",
  "serviceType": [
    "Fallsikring",
    "Taksikring",
    "Linesystem installasjon",
    "Kontroll av fallsikringsutstyr",
    "Fallsikringskurs"
  ]
}
```
